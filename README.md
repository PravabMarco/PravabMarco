<details>
<summary><b>⚙️ How to activate the snake — click to expand</b></summary>

<br/>

Create `.github/workflows/snake.yml` in this repo:

```yaml
name: Generate Snake

on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
      - uses: crazy-max/ghaction-github-pages@v3
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

Then: **Settings → Actions → General → Workflow permissions → Read and write** → Save → run workflow manually once.

## 🧠 &nbsp;My Learning System

```bash
#!/bin/bash
# /etc/prabhav/learning.sh

daily() {
  concept_video_first       # understand before you touch anything
  lab_immediately_after     # KillerCoda · play-with-docker — build it NOW
  commit_to_github          # even if it's tiny. consistency compounds.
}

weekly() {
  read_engineering_blog     # Netflix · Cloudflare · Discord tech blogs
  update_roadmap            # check what's done, plan what's next
  write_one_thing_learned   # forces real understanding, not passive watching
}

never() {
  watch_without_building    # passive = forgetting within 72 hours
  skip_the_error_message    # the error IS the lesson
  google_before_docs        # official docs first, always
}

main() {
  daily && weekly && never
}
```
