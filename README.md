## 👋 Hey, I'm Prabhav

I'm a web developer from Nepal on a mission to get into DevOps. I come from building things with **HTML, Python/Django, and TypeScript** — now I'm learning the infrastructure side: Linux, Docker, CI/CD, Kubernetes, and cloud.

This GitHub is my learning log. Every repo is a real attempt at something, not a tutorial copy-paste.

## 🧠 How I Learn

```bash
$ cat /etc/devops/learning-method.conf

[daily-routine]
morning   = read docs + watch 1 concept video
afternoon = hands-on lab (KillerCoda / play-with-docker)
evening   = build something with what I learned

[weekly]
projects  = push at least 1 real thing to GitHub
writing   = document what confused me + how I solved it
review    = scan changelogs for tools I'm learning

[rule]
never_just_watch = true
always_build     = true
break_things     = intentionally
```
