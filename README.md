<summary>⚙️ Click here — how to activate the snake animation</summary>

**Step 1.** In your `PravabMarco` profile repo, create this file:
`.github/workflows/snake.yml`

```yaml
name: Generate Snake

on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}

      - uses: crazy-max/ghaction-github-pages@v3
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

**Step 2.** Go to: Repo Settings → Actions → General → Workflow permissions → set to **Read and write**

**Step 3.** Go to Actions tab → run the workflow manually once → snake appears in 1–2 minutes ✅

## 🧠 My Learning System

```bash
#!/bin/bash

daily() {
  watch_one_concept_video          # understand what it is
  open_a_lab_immediately_after     # KillerCoda or play-with-docker
  commit_something_to_github       # even if it's tiny
}

weekly() {
  read_one_engineering_blog        # Netflix, Cloudflare, Discord tech blogs
  update_roadmap_progress          # check off what's done, set what's next
  write_what_confused_me           # forces real understanding, not just watching
}

never() {
  watch_without_building           # passive learning = forgetting in 3 days
  skip_the_error_message           # the error IS the lesson
  google_before_reading_the_docs   # official docs first, always
}
```
